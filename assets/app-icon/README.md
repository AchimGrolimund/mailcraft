# MailCraft app icon

A **carrier pigeon with a sealed letter in its beak**: a portrait in the manner of a wood
engraving, three-quarter view, facing left, the head and body filling the tile and the body, the
wing and the letter running off its edges. It follows the icon framing of the Craft apps.

## Palette

Exactly three colours:

| Colour | Hex | Used for |
|---|---|---|
| Ink | `#0b0b0c` | line work, the beak, the eye, the seal |
| Paper | `#efe9dc` | the bird and the letter |
| MailCraft crimson (the app colour) | `#b3202a` | the full-bleed field |

## Geometry

A 512-unit tile, a rounded square with `rx=112`, no border. The figure is clipped to an inner
rounded rectangle inset 6 units with `rx=106`, so a thin band of the app colour wraps it. The
macOS files pad the tile onto Apple's 824/1024 icon grid; the sizes from 16 to 64 px crop 22
units off each side so the figure still reads.

## Where it comes from

The artwork is drawn by `source/draw_art.py`: the curves, the shading lines and the feathers are
written out there, and running it writes `source/mailcraft-art.png` (2048 px). Nothing is
traced, copied or generated by an image model. It is original work of the MailCraft
contributors, under the project's licence (MIT OR Apache-2.0).

`cargo xtask icon` reads that picture, snaps it to the three colours, fits it to the tile and
writes every file here: the `hicolor` PNGs for Linux, `mailcraft.ico` for Windows,
`mailcraft.icns` and `mailcraft-macos-512.png` for macOS, and `mailcraft-1024.png`.
`source/icon.json` names the app colour.

## Changing it

Edit `source/draw_art.py` (it needs Python with Pillow and NumPy), then:

```sh
python assets/app-icon/source/draw_art.py
cargo xtask icon
```

Without `source/mailcraft-art.png`, `cargo xtask icon` falls back to a plain envelope drawn in
`xtask/src/icon.rs`.
