- A message moved into an IMAP account's Outbox can be moved or copied straight into another account; it used to be refused as if it were a draft. If that account refuses it, it comes back to the Outbox and isn't sent. When an agent moves mail into such an Outbox, the question now says the mail stays there unsent, not that it is sent, and the question about importing no longer says imported mail is sent. Undoing a move into such an Outbox no longer leaves the message marked as held ([#451](https://github.com/GITHUB_REPOSITORY/issues/451)).
